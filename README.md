# 双面触感压印数据预检

将正背版绘制坐标注册到同一张纸，输出禁区、越界和凸点间距冲突。 这是处理合成数据的离线参考应用，不依赖网络、数据库服务或第三方库。

```sh
python3 -B -m reliefsheet examples/demo.json
python3 -B -m reliefsheet --merge BASE.json LEFT.json RIGHT.json
python3 -B examples/smoke.py
```

需要 Python 3.9+。传入任意匹配契约的 UTF-8 JSON 文件，输出 JSON 写到标准输出；非法输入使用退出码 2，诊断写到标准错误。业务上发现冲突仍会产生完整分析结果。完整测试套件暂缓；随仓冒烟样例从实际命令行入口验证有效结果与输入拒绝。

格点从 0 开始；背版先水平镜像再叠加偏移。矩形左闭右开；点距为两个轴差的最大值。 详见 [项目说明](PROJECT_SPEC.md) 和 [输入样例](examples/demo.json)。

## 合版

`--merge` 以底稿为基，把两份完整修订合到同一张纸上：

- 标记按面和 ID 识别，比较的是**原绘图坐标**，注册不会掩盖编辑；
- 禁区按 ID 识别，比较原矩形；
- 背版偏移、两类最小距离各是独立对象。

两支改成同一个值只记一笔（`revision_source: both`）。删除对修改、或两支改成不同值会停止合版（`mergeable: false`），不臆造合版值。尺寸固定，任何改动都停止合版。

合版结果给出完整合版文档、两支与合版的报告、逐对象合版图和冲突对照。对照里每条冲突按“规则 + 涉事原对象”认定身份，距离或所需间距变化不另立身份，并标出 `branch-existing`（分支已有）或 `merge-new`（合版新增）。

每个合版新增冲突都带最小成因重放：只枚举该身份依赖的对象（至多两个标记、一个阈值，涉及背版时再加偏移），从底稿出发按编辑条数从小到大找出**全部**最小组合；组合里的偏移和阈值就是重放实际使用的值，重放重新套准并重新判定，不借用完整合版的坐标。每个组合记录两支的修订来源、执行前后的设置、原绘图坐标、注册坐标和完整发现集。

`examples/merge/` 里是可复核的验收样例（`base.json` 是共用底稿）：`both-pass-*`（两支单独通过、合版冲突）、`offset-*`（偏移与移动是同规模的不同最小成因）、`distance-*`（身份相同而距离变动）、`delete-*`（删除对修改停止合版）、`same-value-*`（两支同值只算一笔）、`clean-*`（无新增仍交付合版图与对照）、`replay-*`（合版偏移与成因组合偏移不同，重放必须用组合自身的偏移）。
